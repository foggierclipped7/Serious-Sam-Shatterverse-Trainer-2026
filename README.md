## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Serious Sam: Shatterverse**. This trainer enhances solo runs with control over survivability, ammunition, weapon handling, movement, and progression. It is designed around the game's run-based arena combat, destructive arsenal, boons, run modifiers, anomalies, portals, and boss encounters.

**Target Audience:** Players who want to explore Shatterverse worlds, test weapons and boons, practice against Mental's forces, or complete solo roguelite runs with reduced difficulty.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement enhancement only when traversing large arenas or recovering from difficult encounters. Normal run-and-gun movement remains the best way to evade charging enemies and maintain distance during large enemy waves.

### Tools & Inventory

Shatterverse centers on weapons, boons, run modifiers, and permanent progression rather than a traditional inventory system. Activate ammunition or resource features before selecting upgrades so you can freely test different combinations during a run.

### World & Environment

Runs move through shifting universes and handcrafted arenas with changing routes, hidden portals, and unstable anomalies. Save major trainer features for high-risk areas, optional rewards, and encounters that could otherwise end the run.

### Combat & Weapons

Serious Sam: Shatterverse emphasizes fast first-person arena combat against large groups of classic and new enemies. Unlimited ammunition and no reload are suited to extended firefights, while enemy and boss options should be used selectively for testing or rapid progression.
